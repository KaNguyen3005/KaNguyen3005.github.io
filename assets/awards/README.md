## 💡 Cơ chế hiển thị thông minh (Graceful Fallback)

- Khi **chưa có file ảnh**, website sẽ tự động hiển thị banner placeholder sang trọng (`📷 Ảnh chứng nhận sắp cập nhật`) nhờ thuộc tính `onerror`.
- Khi bạn **copy file ảnh vào thư mục này** với đúng tên file ở bảng trên, ảnh sẽ **tự động xuất hiện ngay lập tức** trên website mà không cần phải chỉnh sửa lại mã nguồn HTML!
